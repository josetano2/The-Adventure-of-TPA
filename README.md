 The Adventures of Tim, Patrick, and Araszkiewicz

A quest-based 3D action RPG built with Unity, developed as part of the Technical Test for Assistant Recruitment at Zinus University.

## 🎮 Game Overview

In this game, players explore a vibrant town and engage in real-time battles to defend a magical crystal. The game features three unique playable characters with distinct playstyles:
- **Tim** – Agile knight with fast attacks.
- **Patrick** – Heavy dog knight with high durability and damage.
- **Araszkiewicz** – Tactical wizard with long-range spells.

Switch between characters, take on quests, visit the shop, and fight enemies using A* pathfinding and real-time combat mechanics.

## 🛠️ Key Features

- 🧠 AI pathfinding using **A-Star algorithm**
- 🌍 Procedural obstacle generation using **BSP & Prim algorithms**
- 🎮 Third-person character control with real-time combat
- 🛒 In-game shop with inventory system and consumables
- 🎼 Adaptive background music and sound design
- 💾 Data persistence & quest progression
- 🎨 Custom assets and environments from Unity Asset Store
